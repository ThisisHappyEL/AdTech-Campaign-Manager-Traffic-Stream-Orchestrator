# Keitaro Stream Manager

Веб-сервис для оркестрации рекламных кампаний и потоков трекера Keitaro: создание кампаний с настроенными правилами маршрутизации, локальный стейджинг изменений (Draft/Staging) и автоматическая балансировка весов офферов.

---

## Возможности

### 1. Создаватор кампаний
- Создание кампании в Keitaro с двумя потоками:
  - **Поток 1 (White / Filter):** фильтр по гео-коду страны (`accept`) с HTTP-редиректом на `https://google.com`.
  - **Поток 2 (Target):** направление остального трафика на выбранный оффер со 100% долей (`share: 100`).
- Автоматическое определение доступных `group_id`, `domain_id` и `traffic_source_id` через API с безопасным фолбэком для тестовых аккаунтов.
- Автоматическая генерация уникального `alias`.

### 2. Редактор потоков (Staging & Weight Balancing)
- **Синхронизация (`Fetch streams`):** загрузка актуального состояния из Keitaro. Отслеживание офферов, удаленных напрямую на стороне трекера.
- **Локальный черновик:** изменения (добавление, удаление) сохраняются только в локальную БД (поток подсвечивается желтым как `Unpublished`).
- **Удаление / Возврат (`Remove` / `Bring back`):** мягкое удаление оффера (помечается серым с весом `0%`) с возможностью восстановления в один клик.
- **Фиксация весов (`Pin`):** закрепленные офферы сохраняют свой вес, а остаток до `100%` делится поровну между незакрепленными активными офферами (с точным распределением остатка до целых процентов).
- **Управление публикацией:** `Push to KT` отправляет итоговые веса в Keitaro (`PUT /streams/{id}`), `Cancel` откатывает локальный черновик к состоянию в трекере.

## Стек технологий

- **Backend:** Python 3.10+, FastAPI, SQLAlchemy 2, Alembic, HTTPX, Pydantic
- **Database:** SQLite (локальное стейджинг-хранилище)
- **Frontend:** HTML5, Tailwind CSS, Vue 3 (через CDN, без необходимости сборки Node.js)

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ThisisHappyEL/AdTech-Campaign-Manager-Traffic-Stream-Orchestrator.git
   cd keitaro-stream-manager
   ```

2. **Создайте виртуальное окружение и установите зависимости:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate   # Linux / macOS / WSL
   # или .venv\Scripts\activate для Windows

   pip install -r requirements.txt
   ```

3. **Настройте окружение (опционально):**
   ```bash
   cp .env.example .env
   # Укажите актуальный KEITARO_API_KEY в .env при необходимости
   ```

4. **Примените миграции базы данных (Alembic):**
   ```bash
   alembic upgrade head
   ```

5. **Запустите сервер:**
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```

6. **Откройте интерфейс в браузере:**
   [http://localhost:8000](http://localhost:8000)
